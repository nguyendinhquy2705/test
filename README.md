This repository contains member-level evidence extraction, screening records, the merged evidence table, and the Week 7 RQ/gap validation artifacts.

3. `team-synthesis/gaplist.md` — gap candidates and evidence status.

5. `team-synthesis/prisma-team.md` — current reconciliation status and PRISMA rules.

## Important status note

This package improves the project structure and documents the checks that can be supported by the supplied records. It does **not** invent missing source quotations, unresolved full-text decisions, effect-size thresholds, or sample-size calculations. Items marked `Needs action`, `Pending`, or `not verified` must be completed from original papers, actual experimental resources, and instructor guidance before the team claims all gates are passed.
