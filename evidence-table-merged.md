# Evidence Table (Merged): Team Synthesis

**Research question (RQ):** When designing black-box tests for 20 frozen functional requirements from PURE, do students using an EP-BVA worksheet or a Decision-Table worksheet achieve higher item coverage compared with the instructor reference inventory?

**Result rule:** Report numerical evidence only when it is supported by a Table or Figure in the original paper. If the relevant Table/Figure has not been verified, report N/A. Abstract-only numerical claims are not verified evidence.

**Relevance rule:** P = students/learners; I = EP-BVA or Decision-Table worksheet; C = the alternative worksheet or the instructor reference inventory; O = item coverage across the 20 PURE requirements. A paper that does not directly investigate these elements is background evidence, not direct evidence.

**Legend:** † = number reported by a team member but the Table/Figure number is not yet recorded in the extraction log (must be verified). N/S = not stated in the paper. Src: S1 = Evidence Table doc 1, S2 = Evidence Table doc 2, S3 = Member 3 table (IEEE Xplore and snowballing), S4 = OpenAlex table; S5 = Member 1 updated evidence table; S6 = Member 3 updated IEEE evidence table.

## 3. Evidence synthesis

The merged set covers requirements-based test generation, EP/BVA/decision-table tooling, and combinatorial coverage. One study (E41) includes student participants, but it compares EP with branch testing and code reading on small C programs. None of the 42 studies compares an EP-BVA worksheet with a Decision-Table worksheet against an instructor reference inventory on the 20 PURE requirements. All studies therefore remain indirect or background evidence for this RQ. The closest conceptual links are: E03 and E05 (decision-table based generation), E01, E02, E07 (BVA/EP with coverage as outcome), and E08, E09, E10 (equivalence partitioning in generation tools).

**Research gap:** the screened set contains no direct evidence on the relative item coverage of EP-BVA and Decision-Table worksheets used by students on the same 20 frozen PURE requirements. The direction and size of any difference can only come from the study's own experiment.
